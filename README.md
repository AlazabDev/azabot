# 🤖 Azabot

**Azabot** is an AI-powered maintenance and operations assistant developed by **AlazabDev**. It helps organizations automate maintenance workflows, manage requests, integrate with business systems, and leverage modern AI capabilities.

---

## 🚀 Features

- 🛠️ Maintenance request management
- 🤖 AI assistant for technical support
- 📊 Dashboard and analytics
- 👥 User authentication and role management
- 📎 File and image attachments
- 🔔 Real-time notifications
- 📱 Responsive web interface
- 🔒 Secure API with authentication
- 🌐 REST API
- 📈 Activity logging and auditing

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/AlazabDev/azabot.git
```

Enter the project directory

```bash
cd azabot
```

Install dependencies

```bash
npm install
```

Configure environment variables

```bash
cp .env.example .env
```

Run the development server

```bash
npm run dev
```
