# تطوير زر عزبوت العائم

## النتيجة
تحويل زر عزبوت الحالي إلى مشغّل صغير وأنيق مستوحى من الصور المرفقة، يتمدد إلى شريط أدوات أفقي قبل فتح المحادثة.

## التنفيذ
- إنشاء حالتين للمشغّل: زر مصغّر، وشريط موسّع بحركة انتقالية ناعمة.
- عرض هوية عزبوت، حالة الاتصال، زر المحادثة، زر المكالمة، اسم الوكيل، وزر فتح النافذة.
- ربط أزرار الشريط بنافذة الدردشة التشغيلية الحالية دون تغيير منطق الرسائل أو Azure Foundry.
- تحديث كود التضمين ليغيّر مساحة الإطار تلقائيًا بين الحالة المصغّرة والموسّعة ونافذة الدردشة، مع بقائه معزولًا فوق الموقع المضيف.
- مراعاة العربية وRTL وشاشات الهاتف وتقليل الحركة عند تفعيل إعداد تقليل الحركة.

## التحقق
- اختبار الحالات الثلاث بصريًا: مصغّر، موسّع، ومحادثة مفتوحة.
- اختبار التضمين فوق صفحة خارجية والتأكد من عدم تحريك أو تغطية محتوى الموقع خارج مساحة الزر.
